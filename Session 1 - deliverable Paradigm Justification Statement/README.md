## Descripción

### English

Defines the doctoral research topic: a reference architecture based on specialised generative AI agents to develop and verify critical State information systems. The application case is the Peruvian pension system.

- **Research question:**

  > How should a reference architecture based on specialized generative AI agents be structured to automate and verify the development of critical state information systems, ensuring their compliance with the enterprise architecture and applicable regulations?

  All later deliverables build on this question.
- **Chosen paradigm:** Design Science Research (DSR), with a pragmatist foundation. The positivist approach is discarded because the aim is not to measure an existing phenomenon; the interpretive approach is discarded because the aim is not to understand stakeholders' perceptions. Mixed methods remain as an evaluation strategy inside DSR.
- **Implications:** a conformance principle with preferably deterministic verification (static analysis and policy-as-code). Metrics: precision and recall, defect escape rate, rework and lead time, against a single-agent baseline.
- **Tensions:** sustained access to the case entity, and possible correlated failures between the generator and verifier agents.

### Español

Define el tema de investigación doctoral: una arquitectura de referencia con agentes de IA generativa especializados para desarrollar y verificar sistemas de información críticos del Estado. El caso de aplicación es el sistema de pensiones peruano.

- **Pregunta de investigación:**

  > ¿Cómo debería estructurarse una arquitectura de referencia basada en agentes de IA generativos especializados para automatizar y verificar el desarrollo de sistemas de información de estado críticos, garantizando su conformidad con la arquitectura empresarial y las normativas aplicables?

  Todos los entregables posteriores parten de esta pregunta.
- **Paradigma elegido:** Design Science Research (DSR), con base pragmatista. Se descarta el enfoque positivista porque no se busca medir un fenómeno existente, y el interpretativo porque no se busca comprender percepciones. Los métodos mixtos quedan como estrategia de evaluación dentro de la DSR.
- **Implicaciones:** un principio de conformidad, con verificación preferentemente determinista (análisis estático y política como código). Métricas: precisión y exhaustividad, tasa de escape de defectos, retrabajo y tiempo de entrega, contra una línea base de un solo agente.
- **Tensiones:** el acceso continuo a la entidad del caso, y la posible correlación de fallas entre el agente generador y el verificador.
