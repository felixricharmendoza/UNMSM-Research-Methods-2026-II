# Datasheet — NVIDIA Aegis AI Content Safety Dataset 1.0 (educational use)

## Motivation
- **Purpose:** Built to train and evaluate LLM content-safety moderation models against a broad risk taxonomy, including the AEGIS ensemble of LLM safety experts (Ghosh et al., 2024).
- **Created by / funded by:** NVIDIA (Ghosh, Varshney, Galinkin, Parisien — verify author list in arXiv:2404.05993). Funding: NVIDIA internal; grant or external funding UNKNOWN — to investigate.

## Composition
- **What instances represent:** One row per text, which is either a user prompt or an LLM response (combined: 3147, llm_response: 3131, user_message: 3099, multi_turn: 1421). Split sizes: 10798 train / 1199 test. Each row has up to 5 annotation columns (labels_0, labels_1, labels_2, labels_3, labels_4); each annotation is 'Safe' or one or more risk categories. Annotations per item: 2 annotation(s): 12, 3 annotation(s): 9751, 4 annotation(s): 1031, 5 annotation(s): 4. Cross-check run: train 10798 vs card 10798: OK; test 1199 vs card 1199: OK; safe/unsafe 3550/7248 vs repo output 3550/7248: OK; annotation columns 5 vs repo code comment 4: MISMATCH (the code itself reads labels_0..labels_4).
- **Labels:** Annotator-level labels from the Aegis taxonomy (13 critical risk categories plus 'Needs Caution'; verify the list on the dataset card). Category frequency in train (assigned by >= 1 annotator): Criminal Planning/Confessions: 2482, Needs Caution: 2098, Hate/Identity Hate: 1253, Harassment: 1034, Violence: 958, PII/Privacy: 757, Sexual: 632, Profanity: 550, Controlled/Regulated Substances: 506, Guns and Illegal Weapons: 399, Other: 188, Suicide and Self Harm: 115, Threat: 101, Sexual (minor): 63, Deception/Fraud: 2, Fraud/Deception: 1, Graphic: 1, Fraud/deception: 1, acting without consent (possible harassment): 1. Binary label used here = repo rule (safe if >= 2 'Safe' votes): unsafe: 7248 (67.1%), safe: 3550 (32.9%) (imbalanced). No official binary label is provided by the creators.
- **Sample vs population:** English prompts taken from Anthropic's HH-RLHF harmlessness red-teaming data plus responses generated by an LLM (Mistral-7B-v0.1 per the dataset card — verify). Adversarial by construction; NOT representative of real user traffic, other languages or of QA questions over enterprise documents.
- **Missing data:** 4 empty texts in train. Empty annotation slots are expected because items have a variable number of annotators (2 annotation(s): 12, 3 annotation(s): 9751, 4 annotation(s): 1031, 5 annotation(s): 4); the reason some items have fewer annotations is UNKNOWN — to investigate.

## Collection process
- **How collected:** Prompts sampled from Anthropic HH-RLHF (harmless-base, red-team conversations); LLM responses generated by the creators; every text labelled by trained human annotators following the Aegis taxonomy and guidelines (Ghosh et al., 2024 — verify annotator count and QA procedure).
- **Timeframe:** Released in 2024 together with arXiv:2404.05993 (April 2024). Annotation period UNKNOWN — to investigate.
- **Consent / ethics:** HH-RLHF prompts were written by crowdworkers hired by Anthropic; their consent terms are those of the original collection (UNKNOWN — to investigate). Annotators were exposed to harmful content; wellbeing measures are described in the paper (verify). Ethics-committee approval: UNKNOWN — to investigate.

## Preprocessing / cleaning / labeling
- **Steps:** Creators' filtering, de-duplication and PII handling: UNKNOWN — to investigate. In this project: (1) binary label derived with the rule from big-qa-architecture src/dataset.py; (2) label-rule audit: repo rule (>=2 'Safe' votes -> safe) vs strict majority of present annotations disagree on 13 of 10798 train items (0.1%); 0 items have a single annotation that says 'Safe' but the repo rule labels them 'unsafe'; 0 items are 'unsafe' under the repo rule although no annotator assigned any risk category; (3) the repo code comment mentions labels_0..labels_3 while the code reads labels_0..labels_4; (4) TF-IDF features at train time (fit on train only).
- **Raw data available:** The per-annotator labels are released (labels_* columns), so other aggregation rules can be applied. The full HH-RLHF conversations are public separately (Anthropic, MIT license — verify). Annotator guidelines in full: UNKNOWN — to investigate.

## Uses
- **Appropriate uses:** Training and benchmarking content-safety classifiers and LLM guardrails; research on annotator disagreement and label aggregation; teaching of responsible-AI documentation.
- **Should NOT be used for:** Training models to GENERATE harmful content; claiming jailbreak-detection performance without out-of-distribution tests (labels describe harm categories, not attack techniques); profiling or decisions about real people; generalising to non-English text.

- **How distributed:** Hugging Face Hub, gated (users must accept NVIDIA's terms): https://huggingface.co/datasets/nvidia/Aegis-AI-Content-Safety-Dataset-1.0. Dataset paper: Ghosh et al. (2024), arXiv:2404.05993.
